What it does

COMMUNICATION

Talk to devices

  • Modbus TCP and Serial (RTU/ASCII) client
  • Network discovery and diagnostics for finding devices on a subnet

MONITORING

Monitor & log

  • Named tag monitoring with alarms and engineering-unit scaling
  • Trend graphing, including recording a session and replaying it later
  • Raw Data view - the actual wire bytes behind every transaction

SIMULATION

Simulate & test

  • Server mode - act as a Modbus TCP slave for testing your own SCADA/PLC program
  • A small scripting language for repeatable write/wait/read test sequences

System Requirements

  • Windows 10 or newer, 64-bit
  • Admin rights for the installer (one UAC prompt during setup)
  • Npcap - optional, only needed for ARP-based discovery and packet capture
